# NeuroFormula

NeuroFormula — система распознавания и решения рукописных математических выражений, разработанная на Python. Искусственный интеллект на базе модели Qwen преобразует написанный от руки пример в цифровое выражение, после чего программа автоматически выполняет вычисления и выводит результат.

## О проекте
Проект объединяет классический калькулятор и режим рукописного ввода. Пользователь может вводить выражения через интерфейс калькулятора или писать математические примеры от руки в отдельном графическом окне.
После распознавания выражение преобразуется в цифровой формат, обрабатывается программой и вычисляется автоматически.

## Использование

### Стандартный режим
При запуске NeuroFormula открывается окно классического калькулятора, позволяющее выполнять вычисления с помощью кнопок интерфейса.

### Режим рукописного ввода
Для перехода в режим распознавания рукописных выражений необходимо нажать кнопку «Рукописный ввод». После этого откроется отдельное окно для графического ввода.

Управление в режиме рукописного ввода:
- Левая кнопка мыши (ЛКМ) — рисование символов и математических выражений.
- Правая кнопка мыши (ПКМ) — стирание фрагментов изображения.
- «Очистить всё» — полностью очищает область рисования и поле результата.
- «Вычислить» — передает изображение на обработку искусственному интеллекту, распознает математическое выражение и выводит результат вычисления.

## Статус проекта

- расширение набора поддерживаемых математических операций;
- сохранение истории вычислений.
